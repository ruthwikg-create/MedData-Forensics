# MedData Forensics — Ink & Mineral UI design system

Reviewed reference guidance: [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill), including priority accessibility, 44×44 touch target, responsive layout, semantic color, reduced motion, feedback and meaningful data visualization. The following are **project-specific choices**, not output claimed to be generated by its CLI.

## Design goals

An editorial, restrained research workbench that prioritizes legibility of evidence, traceability and scientific uncertainty. Avoid neon, overdecorated cards, fake live metrics and overly optimistic 'health scores'. Every visual indicator should have a textual explanation.

Typography: Windows Segoe UI with Inter/system fallback, 14px main UI at 1.55 line-height; heading 27–40px hero, 22px section heading, 17px subheading; Con­solas for hashes and numeric evidence. No network-dependent font files are required. Avoid microtext for vital instructions; small labels are supplementary only.

Spacing: 4pt rhythm; page horizontal gutter 54px desktop, 20px tablet, 15px mobile; cards use 18–26px internal padding; consistent 8–15px gaps; 14px radius for large cards, 8–11px controls.

Responsive: desktop fixed left navigation 254px, medium 223px, mobile collapsible drawer at ≤820px; stat cards 4→2 columns, research layouts 2→1 at tablet widths, image records flow to responsive grid. The topbar always retains dataset selection and import action.

Accessibility: visible focus 3px, native form controls, keyboard-operable graph nodes, semantic button roles, meaningful alternative text, modal focus containment and Escape close, skip link, live notifications, textual severity labels. Selected status never relies on color alone. Recheck at 200% zoom and 375px widths.

Interaction: 150–220ms hover/motion for navigational feedback, no inert controls, explicit busy/empty/failure states, cancellation checkpoints and progress in jobs view. `prefers-reduced-motion` disables animation. Light/dark mode is a live user choice.

Charts: limited bar meters and confusion matrices with numeric labels. Evidence graph nodes have different categories and selectable detail. Keep colors legible, and never represent clinical outcomes with unsupported 'confidence' grades.

Security UX: identifiers displayed in truncated form only for UI convenience with full evidence in details; export flows warn of data-governance responsibilities; sample image requests route through server rather than public static assets.
